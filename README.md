# Aniki — Tienda de pines de anime

Proyecto inicial hecho con HTML, CSS y JavaScript puro.

## Funciones
- Catálogo de pines con creación, edición y eliminación.
- Búsqueda, filtros por categoría y orden por nombre/precio/fecha.
- Inventario, unidades disponibles y valor total calculado.
- Perfil de tienda con WhatsApp, Instagram y TikTok.
- Vista previa de contacto y validación básica de datos.
- Datos guardados en `localStorage` del navegador (no en una base de datos ni compartidos entre dispositivos).
- Diseño adaptable a móvil y escritorio.

## Cómo usarlo
Abre `index.html` en un navegador. También puedes usar la extensión Live Server de VS Code.

## Importante
Esta versión es un prototipo local: los datos se guardan solo en el navegador donde se utiliza. Para un CRUD multiusuario con datos centralizados necesitará un backend/base de datos (por ejemplo, Supabase) y un proceso de despliegue. Los enlaces de redes se usan para facilitar el contacto; el catálogo todavía no procesa pagos ni pedidos automáticamente.
